# ModusBI MCP Server

> ⚠️ **Перед практической работой** прочитайте [../DISCLAIMER.md](../DISCLAIMER.md): изменения на портале необратимы (нет отмены/истории), безопасность доступов при работе с LLM — на стороне пользователя.

ModusBI MCP Server — это сервер [Model Context Protocol](architecture/concepts/what-is-mcp.md), через который ИИ-ассистент строит и настраивает BI-отчёты (дашборды) на аналитическом портале ModusBI. Вместо того чтобы вручную формировать HTTP-запросы к API портала, ассистент вызывает готовые инструменты сервера: создать отчёт, добавить компонент, описать датасет, применить стиль, выполнить запрос к данным. Сервер принимает эти вызовы и сам транслирует их в HTTP-API портала.

Это и есть смысл MCP: единый стандартный протокол даёт ИИ высокоуровневые инструменты с описанием параметров, а детали HTTP-API портала остаются скрытыми. На вход ассистент получает структурированный набор инструментов; на выходе — готовый дашборд: KPI, графики, таблицы, карты, фильтры.

Термины «отчёт» и «дашборд», «компонент» и «виджет» используются как синонимы. Полный список определений — в [GLOSSARY.md](GLOSSARY.md).

## Быстрый старт (запуск из исходников, ~15 минут)

Ниже — запуск сервера из исходников. Скопируйте команды как есть; шаги 4–6 выполняйте в одном и том же сеансе терминала, иначе экспортированные переменные не дойдут до сервера.

```bash
# 1. Клонировать репозиторий
git clone <repo-url> modusbi-mcp
cd modusbi-mcp

# 2. Создать и активировать виртуальное окружение
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Скопировать пример конфигурации и вписать свои значения
cp .env.example .env
#   откройте .env и задайте MODUSBI_URL / MODUSBI_USERNAME / MODUSBI_PASSWORD

# 5. Сервер читает переменные окружения напрямую (.env автоматически не подхватывается).
#    Экспортируйте их вручную в текущем сеансе терминала.
#    Замените значения ниже на адрес своего портала и реальные учётные данные:
export MODUSBI_URL=https://your-portal.example.com
export MODUSBI_USERNAME=your_api_user
export MODUSBI_PASSWORD=your_api_password

# 6. Запустить сервер (по умолчанию режим readonly — только чтение)
python -m app.server
```

Где взять `MODUSBI_URL` / `MODUSBI_USERNAME` / `MODUSBI_PASSWORD`: это адрес вашего портала ModusBI и логин/пароль учётной записи на нём, от имени которой сервер будет обращаться к API. Для production не вписывайте пароль в файлы, а используйте механизм секретов вашей платформы развёртывания.

После запуска сервер общается по протоколу MCP (JSON-RPC 2.0 поверх stdio) и ждёт подключения MCP-клиента. Сам по себе сервер ничего не выводит «как сайт» — чтобы им пользоваться, его нужно **подключить к MCP-клиенту** (например, Claude Desktop). Чтобы убедиться, что всё работает, попросите ассистента в клиенте показать список доступных инструментов (tools) — должны появиться `report_operations`, `dataset_operations`, `component_crud`, `style_operations` и другие.

Минимальная запись для MCP-клиента (`.mcp.json` / `claude_desktop_config.json`); готовый шаблон — [.mcp.example.json](../.mcp.example.json):

```json
{
  "mcpServers": {
    "modusbi": {
      "command": "python",
      "args": ["-m", "app.server"],
      "cwd": "/path/to/modusbi-mcp",
      "env": {
        "MODUSBI_URL": "https://your-portal.example.com",
        "MODUSBI_USERNAME": "your_api_user",
        "MODUSBI_PASSWORD": "your_api_password"
      }
    }
  }
}
```

При запуске через MCP-клиент переменные удобнее задавать в блоке `env` записи сервера — отдельный `export` в shell тогда не нужен. Режим запуска задаётся в `args`: без флага сервер стартует в `readonly`; чтобы разрешить изменения, добавьте `"--readwrite"`.

По умолчанию сервер стартует в режиме `readonly` (доступны только операции чтения и экспорта). Это безопасное состояние: даже ошибочный или неожиданный вызов на изменение будет отклонён. Чтобы разрешить создание и изменение отчётов, запустите с флагом `--readwrite`. Подробнее о режимах — в [start/server-modes.md](start/server-modes.md).
