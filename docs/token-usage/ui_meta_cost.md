# Токен-стоимость UI-метаданных слагов (list_slugs)

> Токенайзер: tiktoken:cl100k_base. Генерируется `scripts/measure_ui_meta_tokens.py`.

**Когда грузится:** только при opt-in префиксе `ui:` в `slug_category`
(`ui:`, `ui:<category>`, `ui:search:<term>`). По умолчанию НЕ грузится — нулевая регрессия.

| режим | default | +ui | Δток | Δ% |
|---|--:|--:|--:|--:|
| default summary (без аргументов) | 1274 | 1274 | +0 | 0% |
| category=legend | 356 | 566 | +210 | 59% |
| category=labels | 801 | 1203 | +402 | 50% |
| search=color (Bar) | 580 | 917 | +337 | 58% |
| component_type=Bar (весь) | 4437 | 6821 | +2384 | 54% |
| component_type=Map (39 слагов) | 5703 | 8612 | +2909 | 51% |

**Вывод:** базовый обзор (`list_slugs()` без аргументов) — **+0** токенов.
UI-мета добавляет ~50-60% и только по явному запросу `ui:`. Приемлемо для уточнения
настроек ОДНОГО компонента/категории (напр. `ui:legend` ≈ +210 ток); для широкого
обзора оставляйте `ui:` выключенным.
