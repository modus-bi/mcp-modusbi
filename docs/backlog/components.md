# Backlog: компоненты

Открытые пункты по настройкам компонентов — по каждому типу. Здесь то, что **не работает,
недостижимо через MCP или требует проверки**. Готовность в процентах — в
[готовности компонентов](../architecture/readiness/components-readiness.md).

**Статусы:** «не отображается» — настройка пишется в конфиг, но визуально не применяется;
«нет настройки» — контрол есть в интерфейсе, но через MCP недостижим; «не проверено» — ещё не
проверялось (нет данных/случая); «поведение неизвестно» — требует дополнительного изучения.
