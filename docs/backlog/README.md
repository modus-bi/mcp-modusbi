# Backlog

Открытые пункты по компонентам, инструментам и инфраструктуре — то, что **не работает, недостижимо
через MCP или требует проверки**. Реализованное сюда не входит. Готовность в процентах — в
[готовности компонентов](../architecture/readiness/components-readiness.md) и
[готовности инструментов](../architecture/readiness/tools-readiness.md).

## Файлы
- [components.md](components.md) — настройки по типам компонентов.
- [tools.md](tools.md) — инструменты и их действия.
- [infrastructure.md](infrastructure.md) — тесты, документация, генераторы, контрактные неоднозначности.

## Статусы
- **не отображается** — настройка пишется в конфиг, но визуально не применяется.
- **нет настройки** — контрол есть в интерфейсе, но через MCP недостижим (нет соответствующей настройки).
- **не проверено** — ещё не проверялось (не было подходящих данных или случая).
- **поведение неизвестно** — требует дополнительного изучения.
