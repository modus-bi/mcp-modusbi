# Каталог типов компонентов

Компонент — отдельный виджет внутри отчёта: график, таблица, карта, KPI-блок, фильтр,
текстовый блок и так далее. Этот файл отвечает на два вопроса:

1. **Какие типы компонентов существуют** — сгруппированный каталог.
2. **Когда какой выбирать** — матрица выбора для самых частых случаев
   (столбцы / линия / круговая / таблица / сводная / карта).

Базовые термины (`компонент`, `датасет`, `config`, `слаг`) определены в
[../../GLOSSARY.md](../../GLOSSARY.md). Как ассистент добавляет и настраивает компоненты —
в [../concepts/components-json-slugs.md](../concepts/components-json-slugs.md).

---

## Как получить актуальный список из сервера

Полный перечень типов отдаёт сам сервер — не нужно держать его в памяти:

```python
component_crud(action="types_list")
```

Действие возвращает машинно-читаемый список с системными именами типов
(`HsBarAMchartsChart`, `HsTableReactabularChart` и т.д.) — это источник истины.
Каталог ниже — человекочитаемая навигация по тем же типам.

> Системное имя типа начинается с префикса `Hs` (например, `HsPieAMchartsChart`).
> Именно его принимает параметр `component_type` при добавлении компонента.

## Каталог типов

Сервер поддерживает около трёх десятков типов компонентов, сгруппированных по назначению.
Часть типов помечена как устаревшие — их не стоит использовать в новых отчётах.

### KPI и индикаторы

Одно-два числа крупно, со сравнением и подсветкой.

| Тип | Системное имя | Назначение |
|---|---|---|
| KPI-панель | `HsTotalsPanelV2` | Итоговое значение крупно; поддерживает дельту и дельту в процентах к сравнению |
| Спидометр / шкала | `HsSpeedometerV2AMcharts` | Значение на круговой шкале «min–max» с зонами |

### Графики

Сравнение, динамика, структура, распределение.

| Тип | Системное имя | Назначение |
|---|---|---|
| Столбчатая | `HsBarAMchartsChart` | Сравнение значений по категориям; вертикальные или горизонтальные столбцы |
| Линейная | `HsLineAMchartsChart` | Динамика по непрерывной оси (как правило, по времени) |
| Area | `HsAreaAMchartsChart` | Динамика с акцентом на объём (заливка под линией) |
| Круговая | `HsPieAMchartsChart` | Доли частей в одном целом |
| Радар | `HsRadarAMchartsChart` | Профиль объекта по нескольким показателям сразу |
| Биржевая (time series) | `HsStockAMchartsChart` | Длинные временные ряды с зумом и прокруткой по дате |
| Пузырьковая | `HsBubbleAMchartsChart` | Три измерения: X, Y и размер пузырька |
| Sunburst | `HsSunburstChart` | Иерархия долей кольцами от центра к краю |
| Параллельные координаты | `HsParallelCoordsChart` | Многомерные строки данных как линии по нескольким осям |
| TreeMap | `HsTreeMap` | Вложенные прямоугольники: размер = величина показателя |
| Tilemap | `HsTilemapChart` | Плитки (квадрат/шестиугольник) с цветовой шкалой |
| Сравнительная | `HsComparisonChart` | Сравнение нескольких объектов по набору показателей; требует данных в «длинном» формате (UNPIVOT) |
| Дерево связей | `HsTreeGraph` | Граф «родитель → потомок»; требует числового идентификатора узла |

### Таблица и сводная

| Тип | Системное имя | Назначение |
|---|---|---|
| Таблица | `HsTableReactabularChart` | Плоская таблица строк и столбцов; сортировка, форматирование колонок, условное оформление |
| Сводная таблица | `HsPivotChart` | Кросс-таблица: поля в строки и столбцы, агрегаты на пересечении, итоги |

### Карта

| Тип | Системное имя | Назначение |
|---|---|---|
| Карта Leaflet | `HsMapLeafletChart` | Гео-данные на карте: точки-маркеры или закраска территорий (хороплет) |

### Фильтры и управление

Не показывают данные сами — управляют тем, что показывают другие компоненты.

| Тип | Системное имя | Назначение |
|---|---|---|
| Панель фильтра | `HsFilterControlPanel` | Выбор значений поля (выпадающий список / список / радио и др.) |
| Иерархический фильтр | `HsHierarchicalFilterPanel` | Фильтр по дереву значений (например, регион → город) |
| Переключатель | `HsSwitchControlPanel` | Переключение между категориями или показателями |

> Чтобы фильтр действительно влиял на данные, его поле добавляют не только в сам фильтр,
> но и в каждый компонент, который он должен фильтровать. Подробнее о фильтрах —
> в [../../GLOSSARY.md](../../GLOSSARY.md).

### Утилитарные

Оформление и навигация; большинству из них датасет не нужен.

| Тип | Системное имя | Назначение |
|---|---|---|
| Текстовый блок | `HsTextBlock` | Произвольный текст и HTML (заголовки, пояснения, выводы) |
| Подзаголовок | `HsSubheaderComponent` | Разделитель-заголовок секции отчёта |
| Изображение | `HsImagePanel` | Картинка (логотип, иллюстрация), при необходимости со ссылкой |
| Встроенная страница (iframe) | `HsIframe` | Внешняя веб-страница или видео внутри отчёта |
| Панель вкладок | `HsTabsPanel` | Кнопки навигации между страницами / отчётами |
| Контейнер страниц | `HsPageContainer` | Группирующий контейнер для многостраничной раскладки |

### Устаревшие

Поддерживаются для совместимости, но не рекомендуются в новых отчётах:
`HsPivotOrbChart`, `HsPivotMdxChart`. Для сводных данных используйте
`HsPivotChart`.

## Матрица выбора: когда какой компонент

Самый частый вопрос — «столбцы, линия, круговая, таблица, сводная или карта?». Ориентир —
по тому, **на какой вопрос отвечают данные**.

| Нужно показать | Берите | Почему не другое |
|---|---|---|
| Сравнить величину по категориям (регионы, товары, филиалы) | Столбчатая `HsBarAMchartsChart` | Линия подразумевает непрерывность; круговая годится лишь для долей |
| Динамику показателя во времени | Линейная `HsLineAMchartsChart` | Столбцы загромождают длинный ряд; для очень длинных рядов — биржевая |
| Динамику с акцентом на накопленный объём | Area `HsAreaAMchartsChart` | Чистая линия не передаёт «массу» под кривой |
| Доли частей в целом (немного категорий) | Круговая `HsPieAMchartsChart` | При большом числе долей читается плохо — тогда столбцы или TreeMap |
| Точные значения, много колонок, сортировка | Таблица `HsTableReactabularChart` | График показывает форму, но не точные числа по строкам |
| Срез «строки × столбцы» с агрегатами и итогами | Сводная `HsPivotChart` | Плоская таблица не сворачивает данные по двум измерениям сразу |
| Данные с географией (координаты или территории) | Карта `HsMapLeafletChart` | Столбцы/таблица не передают пространственное распределение |
| Иерархию долей (категория → подкатегория) | TreeMap `HsTreeMap` или Sunburst `HsSunburstChart` | Круговая показывает только один уровень |
| Зависимость трёх числовых величин сразу | Пузырьковая `HsBubbleAMchartsChart` | Линия/столбцы — максимум два измерения |
| Одно ключевое число со сравнением | KPI-панель `HsTotalsPanelV2` | График ради одного числа избыточен |

### Подсказки по краям

- **Столбцы или линия.** Категории (несвязанные между собой значения) — столбцы.
  Непрерывная ось, особенно время, — линия.
- **Круговая или столбцы.** Круговая читаема при немногих долях. Много категорий —
  переходите на столбцы (или TreeMap для иерархии).
- **Таблица или сводная.** Нужен плоский список строк — таблица. Нужно свернуть данные по
  двум измерениям с итогами на пересечении — сводная.
- **Карта или столбцы по территориям.** Карта нужна, когда важна именно география
  (где, рядом ли). Если важен только рейтинг территорий — быстрее и понятнее столбцы.
- **Сравнительная диаграмма** (`HsComparisonChart`) ожидает данные в «длинном» формате
  (одна строка = объект + название показателя + значение). Без такой формы данных она не
  строится.
