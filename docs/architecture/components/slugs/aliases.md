# Слаги: псевдонимы и устаревшие имена

Сервер принимает часть слагов под альтернативными (старыми) именами и помечает часть имён
как устаревшие. Это не история версий, а текущее поведение приёма имён: псевдоним
автоматически приводится к актуальному слагу, устаревшее имя принимается, но рекомендуется
использовать актуальное.

## Псевдонимы (альтернативное имя → актуальное)

| Старый слаг | Актуальный слаг |
|---|---|
| `donut` | `showDonut` |

## Устаревшие слаги (использовать замену)

| Слаг | Статус | Замена / комментарий |
|---|---|---|
| `map.clusterMarkers` | устарел | кластеризация = map.markers.clustering (clusterizationOff) |
| `viewType.resetEnabled` | устарел | нет такого параметра отображения; использовать viewType.updateOnApply/updateOnCloseDropdown |
| `viewType.showAll` | устарел | нет такого параметра отображения |
| `visuals.fillOpacity` | устарел | использовать по-серийный visuals.<series>.fillColor (rgba с прозрачностью) |

> Замена применяется автоматически на стороне сервера; устаревшие слаги принимаются, но рекомендуется переходить на актуальные имена.
