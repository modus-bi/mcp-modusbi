# Текстовый блок

Тип компонента: `HsTextBlock`

## Описание

Текстовый блок — утилитарный компонент для размещения произвольного HTML-контента на дашборде: заголовков разделов, пояснений, аналитических выводов, статических таблиц и списков, разделителей между группами компонентов. Содержимое задаётся напрямую HTML-строкой через параметр `text_content`; в JSON-конфиге оно хранится в ключе `description` (и его локализованной копии `description__ru`).

Этот тип не привязан к датасету и не загружает данные из источников — он лишь отображает переданную разметку. Поддерживается обычный набор HTML-тегов: заголовки, абзацы, списки, таблицы, ссылки, а также inline-стили (`style="..."`) для фона, отступов, цветов и градиентов.

Санитизация выполняется на стороне сервера и носит базовый характер: вырезаются теги `<script>`, обработчики событий (`onclick`, `onload` и т. п.) и схема `javascript:` в ссылках. Остальная разметка отображается как есть.

## Когда применять

- Заголовок раздела или баннер-пояснение на всю ширину дашборда.
- Аналитический вывод или комментарий рядом с графиком («так что же это значит»).
- Статическая таблица или список показателей, которые не нужно тянуть из датасета.
- Визуальный разделитель между логическими блоками отчёта.
- Подпись или инструкция для пользователя.

## Когда не подходит

- Показ данных из датасета — используйте [таблицу](table.md) или [сводную таблицу](pivot-table.md).
- KPI-показатели с динамическими значениями — используйте [панель итогов](totals-panel.md) (`HsTotalsPanelV2`).
- Размещение изображения по ссылке — используйте [панель изображения](image-panel.md) (`HsImagePanel`).
- Встраивание внешней страницы — используйте [iframe](iframe.md) (`HsIframe`).
- Навигация между разделами/страницами — используйте [панель вкладок](tabs-panel.md) (`HsTabsPanel`).

## Контент

> Определения датасета, осей и агрегации см. в [Глоссарии](../../../GLOSSARY.md).

Датасет не требуется: компонент относится к утилитарным типам без привязки к данным (у него нет осей, фильтров и агрегации). Единственный носитель содержимого — HTML-строка:

- Передаётся параметром `text_content` при добавлении.
- Сервер кладёт её одновременно в `config.description` и в авто-копию `config.description__ru` (заполняется тем же значением при создании), чтобы контент корректно отображался в русскоязычном интерфейсе.
- Поддерживаются заголовки (`<h1>`–`<h6>`), абзацы, форматирование (`<strong>`, `<em>`, `<u>`, `<s>`, `<code>`), списки (`<ul>`/`<ol>`), таблицы, ссылки и блоки с inline-стилями.

Заголовок панели (`title`) при добавлении через `add_text_block` скрыт (`showtitle=false`) — на дашборде виден только сам HTML-контент. Текстовый блок при добавлении исключается из экспорта: для этого типа применяется специфичный слаг `text.noexport=true`, который переопределяет универсальный `noexport`.

## Параметры добавления

Для создания текстового блока используется отдельное действие `add_text_block` (не общий `add`).

| Параметр | Назначение |
|----------|-----------|
| `report_id` | Отчёт, в который добавляется компонент (обязателен) |
| `title` | Заголовок компонента (виден только при `showtitle=true`) |
| `text_content` | HTML-содержимое блока — основной контент |
| `position` | Координаты и размер `{x, y, w, h}`; если не задан, компонент ставится внизу дашборда |
| `showtitle` | Показывать заголовок панели над контентом (по умолчанию `false`) |

Тонкая настройка доступна через `config_overrides`. Специфичные для этого типа слаги — `text.noexport` (исключение из экспорта) и `text.maximizable` (разворот на весь экран); они переопределяют одноимённые универсальные настройки для `HsTextBlock`. Также применимы общие оформительские слаги (`bgColor`, `margin.*`, `outline.*`); см. таблицу «Все настройки» ниже.

## Пример

Полноширинный заголовок раздела в верхней части дашборда:

```python
component_crud(
    action="add_text_block",
    report_id=35,
    title="Заголовок",
    text_content='<h2 style="text-align:center;color:#1565c0;margin:0;padding:8px;">Анализ продаж по регионам — 2025</h2>',
    position={"x": 0, "y": 0, "w": 48, "h": 2},
)
```

Аналитический вывод с цветовым акцентом (фон-градиент и левая полоса) — оформление задаётся inline-стилями прямо в HTML:

```python
text_content = '''<div style="background:linear-gradient(135deg,#e8f5e9,#c8e6c9);padding:16px;border-radius:8px;border-left:5px solid #66bb6a;">
  <h2 style="color:#2e7d32;margin:0 0 8px 0;">Цель достигнута</h2>
  <p style="margin:4px 0;"><strong>Рост выручки:</strong> +18% к прошлому году</p>
  <p style="margin:4px 0;"><strong>Выполнение плана:</strong> 104%</p>
</div>'''

component_crud(
    action="add_text_block",
    report_id=35,
    title="Итог",
    text_content=text_content,
    position={"x": 0, "y": 20, "w": 24, "h": 6},
)
```

Обновление содержимого выполняется общим действием `update` с тем же параметром `text_content`:

```python
component_crud(
    action="update",
    report_id=35,
    component_idx=6,
    text_content="<div><p>Обновлённый текст вывода.</p></div>",
)
```

Здесь `component_crud` — это RPC-метод MCP-сервера (вызов инструмента), а не REST-эндпоинт; `component_idx` — 0-based индекс компонента в отчёте.

## JSON-конфигурация

Сервер собирает и хранит конфигурацию компонента в JSON. Ниже — аннотированная структура текстового блока: рядом с каждым ключом указано, что он задаёт. У утилитарного типа нет осей данных, серий и агрегации — только контент и оформление контейнера.

```jsonc
{
  "type": "HsTextBlock",                          // тип компонента (его отдаёт component_crud action="types_list")
  "config": {
    "title": "Итог",                              // заголовок панели (виден только при showtitle=true)
    "description": "<div>…HTML…</div>",            // ОСНОВНОЙ КОНТЕНТ — HTML-строка (из параметра text_content)
    "description__ru": "<div>…HTML…</div>",        // авто-копия description (заполняется тем же значением при создании)
    "chartType": "textBlock",                      // внутренний тип (фиксирован)
    "showtitle": false,                            // показывать заголовок панели над контентом   ← слаг showtitle
    "maximizable": true,                           // разрешить разворот на весь экран            ← слаг text.maximizable
    "noexport": true,                              // исключить из экспорта (для текстблока true) ← слаг text.noexport переопределяет универсальный noexport
    "nocopy": false,                               // запрет копирования содержимого              ← слаг nocopy
    "autoApply": true,                             // служебный флаг (текстблок не участвует в применении фильтров)
    "dirty": false,                                // служебный флаг несохранённых изменений
    "margin":  { "l": 10, "r": 10, "t": 10, "b": 10, "pad": 0 },  // отступы контейнера (выставляются при создании) ← слаги margin.l/r/t/b/pad
    "outline": { "enabled": false, "width": 4 },                   // рамка вокруг блока          ← слаги outline.enabled/width/color
    "filters": {},                                 // служебное: текстблок не принимает фильтры (всегда пусто)
    "filtersDefault": {},                          // служебное: значения фильтров по умолчанию (всегда пусто)
    "visuals": []                                  // служебное: визуальные параметры серий (всегда пусто)
  }
}
```

> Цвет фона (`bgColor`) в дефолтном конфиге не задан — фон прозрачный, и сквозь блок просвечивает фон дашборда. Чтобы задать фон, передайте слаг `bgColor` через `config_overrides` либо используйте inline-стиль в HTML.

Каждый ключ внутри `config` соответствует строке в таблице ниже. Колонка **JSON-путь** показывает, где значение хранится в конфиге. Пустой путь означает верхний уровень `config`.

## Все настройки (config_overrides)

Полный перечень слагов этого типа — специфичные для типа и общие оформительские. Колонки: **UI-контрол** — название в панели настроек портала (пусто = прямого UI-контрола нет, настройка только через `config_overrides`); **MCP-слаг** — ключ в `config_overrides`; **JSON-путь** — куда настройка пишется в конфиг и откуда её читает отображение (это и есть «фронт-ключ»; путь в `(скобках)` обрабатывается секционно — итоговый ключ внутри указанной секции конфига); **Тип**; **По умолчанию**. Полный справочник по всем типам — [Справочник настроек](../slugs/by-type.md).
