# Панель вкладок

Тип компонента: `HsTabsPanel`

## Описание

Панель вкладок — утилитарный контейнер навигации: горизонтальная полоса кнопок для перехода между отчётами, открытия внешних ссылок или запуска HTTP-запросов. Компонент не привязан к датасету и не содержит собственных данных — он только переключает контекст и ведёт пользователя между связанными дашбордами.

Каждая кнопка выполняет одно из двух действий:

- **Переход по ссылке** (`actionType: "openURL"`) — на внутренний отчёт, форму или внешний URL, в текущей или новой вкладке. При переходе панель по умолчанию передаёт глобальные фильтры и переменные отчёта, обеспечивая сквозную фильтрацию.
- **Отправка HTTP-запроса** (`actionType: "sendRequest"`) — метод GET/POST/PUT/PATCH/DELETE к произвольному API, опционально с подтверждением.

Датасет не требуется: компонент относится к утилитарным типам без привязки к данным — у него нет осей, фильтрации и агрегации.

## Когда применять

- Навигация между связанными отчётами (например, «Обзор» → «Детализация» → «Сравнение»).
- Верхнее меню для группы отчётов с единым визуальным стилем.
- Передача текущих фильтров и переменных в целевой отчёт при переходе.
- Запуск серверного действия по кнопке (обновление кэша, отправка данных и т. п.).

## Когда не подходит

- Переключение компонентов **внутри одного** отчёта — используйте контейнер страниц или панель переключений.
- Фильтрация данных — используйте панель фильтра.
- Простой текстовый разделитель между блоками — используйте подзаголовок или текст-блок.

## Навигация и кнопки

Панель не имеет осей и полей данных. Её содержимое — массив кнопок в `config.visuals`; каждая кнопка задаёт текст, цвета, действие и параметры перехода. Кнопки добавляются и удаляются через RPC-метод `component_axes`:

- `tabs_button_list` — перечислить кнопки панели;
- `tabs_button_add` — добавить кнопку навигации;
- `tabs_button_delete` — удалить кнопку по индексу.

> Полный перечень действий метода `component_axes` — см. [Справочник инструментов](../../tools/tool-reference.md).

Активная кнопка (текущий отчёт) задаётся вручную: у неё `link = null` и отдельные цвета (контрастный текст и фон). Система не подсвечивает активную вкладку автоматически — задавайте стиль активной кнопки в каждом отчёте отдельно.

## Параметры добавления

Сам компонент добавляется как утилитарный (без датасета и осей):

| Параметр | Назначение | Обязателен |
|----------|-----------|:---:|
| `component_type` | Тип компонента — `"HsTabsPanel"` | да |
| `x`, `y`, `w`, `h` | Позиция и размер панели в сетке отчёта (типично `y=0`, верхняя строка) | да |
| `title` | Заголовок компонента (по умолчанию скрыт, `showtitle=false`) | нет |
| `config_overrides` | Слаги панели: ориентация, высота, автоприменение (см. ниже) | нет |

Кнопки добавляются отдельно методом `component_axes(action="tabs_button_add")`. Его параметры:

| Параметр | Назначение | Обязателен |
|----------|-----------|:---:|
| `component_idx` | 0-based индекс панели в отчёте | да |
| `title` | Текст кнопки | да |
| `config_overrides.link` | URL перехода: `"/report/{id}"`, `"form/{id}"`, `"https://…"`; не задан = активная кнопка | нет |
| `config_overrides.link_target` | Куда открыть: `"_self"` (та же вкладка) или `"_blank"` (новая) | нет |
| `config_overrides.fill_color` | Цвет фона кнопки (RGBA) | нет |
| `config_overrides.text_color` | Цвет текста кнопки (RGBA) | нет |
| `config_overrides.font_size` | Размер шрифта в rem (по умолчанию `1.3`) | нет |

## Пример

Добавление панели вкладок и трёх кнопок навигации:

```python
# 1. Панель вкладок (без датасета) во всю ширину верхней строки
component_crud(
    action="add",
    report_id=35,
    component_type="HsTabsPanel",
    title="Навигация",
    x=0, y=0, w=48, h=2,
    config_overrides={
        "tabs.orientation": "h",
        "tabs.height": 33,
    },
)

# 2. Активная кнопка (текущий отчёт): link не задаём → null
component_axes(
    action="tabs_button_add",
    report_id=35,
    component_idx=0,
    title="Обзор",
    config_overrides={
        "text_color": "rgba(0,0,0,1)",
        "fill_color": "rgba(242,242,242,1)",
    },
)

# 3. Переход на другой отчёт в той же вкладке (фильтры передаются)
component_axes(
    action="tabs_button_add",
    report_id=35,
    component_idx=0,
    title="Детализация",
    config_overrides={
        "link": "/report/42",
        "link_target": "_self",
    },
)

# 4. Внешняя ссылка в новой вкладке
component_axes(
    action="tabs_button_add",
    report_id=35,
    component_idx=0,
    title="Документация",
    config_overrides={
        "link": "https://example.com/docs",
        "link_target": "_blank",
    },
)
```

Здесь `component_crud` и `component_axes` — это RPC-методы MCP-сервера (вызов инструмента), а не REST-эндпоинты; `component_idx` — 0-based индекс компонента в отчёте. Вызов `component_crud(action="add")` возвращает индекс созданного компонента — используйте его как `component_idx` для последующего добавления кнопок.

## JSON-конфигурация

Сервер собирает и хранит конфигурацию панели в JSON. Ниже — аннотированная структура (выверена по билдеру): рядом с ключами указано назначение и управляющий слаг.

```jsonc
{
  "type": "HsTabsPanel",                  // тип компонента (его отдаёт component_crud action="types_list")
  "config": {
    "title": "Навигация",                 // заголовок компонента
    "chartType": "tabsPanel",             // внутренний тип (фиксирован)
    "showtitle": false,                   // показывать заголовок (по умолчанию скрыт)
    "maximizable": false,                 // разворачивание на весь экран (отключено)
    "noexport": true,                     // экспорт панели запрещён
    "nocopy": false,                      // запрет копирования
    "autoApply": true,                    // автоприменение                  ← слаг tabs.autoApply
    "orientation": "h",                   // ориентация полосы кнопок         ← слаг tabs.orientation
    "height": 33,                         // высота полосы кнопок (px)         ← слаг tabs.height
    "bgColor": "rgba(255,255,255,1)",     // цвет фона панели                  ← слаг bgColor
    "margin":  { "l": 0, "r": 0, "t": 0, "b": 0, "pad": 0 },   // отступы      ← слаги margin.*
    "outline": { "enabled": false, "width": 1 },               // рамка        ← слаги outline.*
    "filters": {},                        // служебное: панель не принимает фильтры (всегда пусто)
    "filtersDefault": {},                 // служебное: значения фильтров по умолчанию (всегда пусто)
    "variables": {},                      // переменные, передаваемые при переходе
    "visuals": [                          // массив кнопок-вкладок            ← слаг tabs.visuals
      {
        "anchor": "Обзор",                //   якорь/идентификатор кнопки
        "labelText": "Обзор",             //   текст на кнопке
        "labelText__ru": "Обзор",         //   локализованный текст
        "color": "rgba(0,0,0,1)",         //   цвет текста (config_overrides.text_color)
        "fillColor": "rgba(242,242,242,1)", // цвет фона   (config_overrides.fill_color)
        "font": { "size": 1.3 },          //   размер шрифта, rem (config_overrides.font_size)
        "actionType": "openURL",          //   действие: "openURL" | "sendRequest"
        "link": null,                     //   URL перехода; null = активная кнопка
        "linkTarget": "_self",            //   "_self" | "_blank" (config_overrides.link_target)
        "noDrillOut": false               //   false = передавать фильтры в целевой отчёт
      }
    ],
    "dirty": false                        // служебный флаг несохранённых изменений (не редактировать вручную)
  }
}
```

> Кнопка с `actionType: "sendRequest"` вместо `link`/`linkTarget` использует поля `requestType` (метод), `requestUrl`, `requestHeaders`, `requestBody`, `requestConfirm`. Такие кнопки настраиваются в веб-редакторе отчёта.

> При переходе на внешний сайт во встроенном фрейме помните про ограничение `X-Frame-Options`: многие сайты запрещают показ внутри фрейма — открывайте их в новой вкладке (`link_target="_blank"`).

## Все настройки (config_overrides)

Полный перечень слагов этого типа — специфичные для типа и общие оформительские. Колонки: **UI-контрол** — название в панели настроек портала (пусто = прямого UI-контрола нет, настройка только через `config_overrides`); **MCP-слаг** — ключ в `config_overrides`; **JSON-путь** — куда настройка пишется в конфиг и откуда её читает отображение (это и есть «фронт-ключ»; путь в `(скобках)` обрабатывается секционно — итоговый ключ внутри указанной секции конфига); **Тип**; **По умолчанию**. Полный справочник по всем типам — [Справочник настроек](../slugs/by-type.md).
