# Аудиоплеер

Тип компонента: `HsAudioplayer`

## Описание

Аудиоплеер воспроизводит аудиозапись по ссылке прямо внутри дашборда. Это специализированный компонент: помимо проигрывания он умеет показывать синхронную текстовую расшифровку (транскрипцию) записи с выделением текущего фрагмента в реальном времени (синхронизация по таймкодам) и цветовыми маркерами (эмоциональная окраска, перебивания и т.п.). Типичное применение — прослушивание записей разговоров с разбором их содержимого.

Сама ссылка на аудио и параметры воспроизведения задаются URL-шаблоном, в который подставляется значение поля из выбранной записи. Поля с расшифровкой (таймкоды, канал, слова, маркеры) поступают из набора данных и отображаются как синхронная транскрипция.

## Когда применять

- Прослушивание и разбор аудиозаписей (например, разговоров) с привязкой к строкам отчёта.
- Контроль качества: запись + синхронная расшифровка + цветовые маркеры проблемных мест.
- Дашборды детализации по конкретной записи, выбираемой из таблицы или фильтра.

## Когда не подходит

- Простое проигрывание аудио без транскрипции — проще встроить плеер через [iframe](iframe.md).
- Видео — компонент работает только со звуком.
- Массовое прослушивание — плеер показывает одну запись за раз.
- Если у данных нет пословной разметки с таймкодами — синхронная подсветка не будет работать; плеер покажет запись и текст без выделения текущей фразы.
- Если в датасете нет полей транскрипции (таймкоды начала/конца, канал, текст) — транскрипция не отобразится, останется только проигрывание по ссылке.

## Поля и данные

Под «записью» здесь понимается один разговор (или иной аудиофрагмент), для которого в датасете лежит набор строк — по строке на каждый фрагмент транскрипции. Выбор записи переключает плеер на её строки. Компонент использует две оси:

- **Значения** (`values`) — поля выбранной записи: ссылка/идентификатор аудиофайла, таймкоды фрагментов (начало/конец), канал звучания, текст фрагмента и маркеры (эмоция, перебивание и пр.). Эти поля наполняют транскрипцию и формируют URL аудио.
- **Фильтры** (`filters`) — поле-ключ записи (например, идентификатор разговора). Плеер показывает строки только выбранной записи; без выбора выводится приглашение выбрать запись.

Агрегация **не применяется ни к одному полю** аудиоплеера — плеер работает с исходными строками записи без агрегирования.

> Поля и привязка к датасету при добавлении через MCP не передаются (компонент добавляется «пустым»), а настраиваются отдельными действиями: поле-ключ оси `filters` — через `component_filters(action="filter_field_add", ...)`, поля транскрипции оси `values` — в панели настроек компонента на портале.

Поле-ключ удобно связать с глобальным фильтром отчёта: alias поля-ключа регистрируется в глобальных фильтрах, и тогда выбор строки в таблице (через переход/drill-down) переключает запись в плеере. При смене записи во время проигрывания плеер останавливается и сбрасывается.

## Параметры добавления

Датасет при добавлении не требуется: поля и `dataset_id` не передаются, плеер создаётся пустым, а данные и URL настраиваются после. Доступные параметры:

| Параметр | Назначение |
|----------|-----------|
| `x`, `y`, `w`, `h` | Позиция и размер компонента в сетке отчёта |
| `title` | Заголовок компонента (показ управляется слагом `showtitle`) |
| `config_overrides` | Слаги плеера: ссылка на аудио, ссылка на скачивание, цвета, отступы, рамка |

Ссылка на аудио и оформление задаются слагами `audio.*` (специфичные для типа) и общими оформительскими слагами (`margin.*`, `outline.*` и т.д.) — полный перечень в таблице ниже.

## Пример

Добавление плеера и настройка ссылки на аудио. `audio.url` — обязательная настройка: без неё проигрывать нечего. В URL-шаблоне фрагмент `{{имя_поля}}` заменяется значением одноимённого поля из первой строки выбранной записи. Ниже `link2coder` — имя поля датасета со ссылкой/идентификатором аудиофайла.

```python
component_crud(
    action="add",
    report_id=35,
    component_type="HsAudioplayer",
    title="Аудиоплеер",
    x=0, y=0, w=24, h=16,
    config_overrides={
        "audio.url": "https://media.example.com/audio?file={{link2coder}}",
    },
)
```

С кнопкой скачивания и фирменным цветом плеера. Кнопка скачивания появляется только при непустом `audio.uploadURL`:

```python
component_crud(
    action="add",
    report_id=35,
    component_type="HsAudioplayer",
    title="Запись разговора",
    x=0, y=0, w=24, h=16,
    config_overrides={
        "audio.url":        "https://media.example.com/stream?id={{link2coder}}",
        "audio.uploadURL":  "https://media.example.com/download?id={{link2coder}}",
        "audio.progressBarColor": "rgba(0, 86, 231, 1)",
        "audio.backgroundColor":  "rgba(240, 248, 255, 1)",
    },
)
```

Чтобы запись выбиралась из таблицы, добавьте на ту же страницу таблицу с переходом по полю-ключу (например, идентификатору записи) в глобальный фильтр отчёта — плеер подхватит ключ через ось фильтров.

Здесь `component_crud` — это RPC-метод MCP-сервера (вызов инструмента), а не REST-эндпоинт; `component_idx` в других действиях — 0-based индекс компонента в отчёте.

## Формат данных

Датасет должен возвращать строки с пословной (или пофрагментной) разбивкой записи: на каждый фрагмент — отдельная строка со служебными полями транскрипции (таймкод начала, таймкод конца, канал, текст фрагмента, маркеры). Поле со ссылкой/идентификатором аудиофайла, длительность и подобные «общие» атрибуты записи берутся из первой строки выбранной записи. Имя поля-ссылки подставляется в URL-шаблон (`{{имя_поля}}`); его можно переименовать, тогда в шаблоне используется новое имя. Имена остальных служебных полей транскрипции фиксированы — плеер читает их по этим именам, поэтому переименовывать эти поля в датасете нельзя.

## JSON-конфигурация

Сервер собирает и хранит конфигурацию компонента в JSON. Ниже — аннотированная структура аудиоплеера (выверена по билдеру): рядом с ключами указано, что они задают и каким слагом управляются.

```jsonc
{
  "type": "HsAudioplayer",                       // тип компонента (его отдаёт component_crud action="types_list")
  "config": {
    "title": "Аудиоплеер",                       // заголовок компонента
    "chartType": "audioplayer",                  // внутренний тип (фиксирован)
    "visualType": "area",                        // технический параметр (фиксирован билдером), на отображение не влияет
    "orientation": "v",                          // ориентация (вертикальная)
    "showtitle": true,                           // показывать заголовок            ← слаг showtitle
    "noexport": false,                           // запретить экспорт               ← слаг noexport
    "nocopy": false,                             // запретить копирование           ← слаг nocopy
    "resource": {                                // ссылки аудио
      "url": "",                                 //   URL-шаблон воспроизведения     ← слаг audio.url      (json_path resource.url)
      "uploadURL": ""                            //   URL-шаблон скачивания (опц.)    ← слаг audio.uploadURL (json_path resource.uploadURL)
    },
    "backgroundColor": "",                       // цвет фона плеера                ← слаг audio.backgroundColor
    "progressBarColor": "rgba(0, 139, 139, 1)",  // цвет прогрессбара и кнопок      ← слаг audio.progressBarColor
    "progressBarBackgroundColor": "",            // цвет незаполненной части бара    ← слаг audio.progressBarBackgroundColor
    "margin":  { "l": 0, "r": 0, "t": 0, "b": 0, "pad": 0 },   // отступы           ← слаги margin.l/r/t/b/pad
    "outline": { "enabled": false, "width": 4 },               // рамка             ← слаги outline.enabled/width
    "axes": [                                    // оси данных (поля настраиваются отдельно)
      { "name": "values",  "type": "values",  "title": "Значения", "visible": true, "fields": [] },  // поля записи и транскрипции
      { "name": "filters", "type": "filters", "title": "Фильтры",  "fields": [] }                    // поле-ключ выбора записи
    ]
  }
}
```

> `audio.url` и `audio.uploadURL` записываются по json-путям `resource.url` и `resource.uploadURL`. При пустом `audio.uploadURL` кнопка скачивания не отображается. Цвет `audio.progressBarColor` влияет и на прогрессбар, и на кнопки управления плеером.

## Все настройки (config_overrides)

Полный перечень слагов этого типа — специфичные для типа и общие оформительские. Колонки: **UI-контрол** — название в панели настроек портала (пусто = прямого UI-контрола нет, настройка только через `config_overrides`); **MCP-слаг** — ключ в `config_overrides`; **JSON-путь** — куда настройка пишется в конфиг и откуда её читает отображение (это и есть «фронт-ключ»; путь в `(скобках)` обрабатывается секционно — итоговый ключ внутри указанной секции конфига); **Тип**; **По умолчанию**. Полный справочник по всем типам — [Справочник настроек](../slugs/by-type.md).
