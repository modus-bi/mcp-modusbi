# Встраиваемый фрейм (iFrame)

Тип компонента: `HsIframe`

## Описание

Встраиваемый фрейм — утилитарный компонент-контейнер для показа внешнего объекта внутри дашборда: веб-страницы, документа (PDF, Google Docs), видеоплеера, интерактивного медиа или другого веб-приложения. Технически компонент рендерит HTML-тег `<iframe>` с атрибутом `src`, указывающим на целевой URL.

Это вспомогательный элемент, а не диаграмма. Работает в двух режимах:

- **Статический** — показывает фиксированный URL, заданный при добавлении. Датасет не требуется. Рендер читает адрес из ключа `frameUrl`; для совместимости с API тот же URL дублируется в `link.name`.
- **Динамический** — URL берётся из набора данных: поле со ссылкой кладётся на ось значений, а поле-ключ — на ось ключей; тогда отображаемый адрес меняется в зависимости от выбора фильтра. Применяется редко — типовой сценарий это статический фрейм с фиксированным адресом.

## Когда применять

- Встраивание внешней веб-страницы, сервиса или приложения внутри дашборда.
- Показ документов по прямой ссылке (PDF, Google Docs).
- Встраивание видеоплеера (для YouTube — URL вида `/embed/{VIDEO_ID}`).
- Динамическая смена документа/страницы по фильтру дашборда.
- Интеграция с внешним BI-инструментом или веб-приложением.

## Когда не подходит

- Для статического изображения — используйте [панель изображения](image-panel.md).
- Для форматированного текста — используйте [текстовый блок](text-block.md).
- Для навигации между страницами/отчётами — используйте [панель вкладок](tabs-panel.md) или [контейнер страниц](page-container.md).
- Если целевой сайт запрещает встраивание заголовком `X-Frame-Options: DENY`/`SAMEORIGIN` — содержимое не отобразится (см. ниже).
- Если нужна двусторонняя интеграция данных — фрейм не передаёт данные обратно в дашборд.

## Датасет и контент

**Датасет в статическом режиме не требуется**: фрейм добавляется без привязки к данным, URL задаётся слагом `iframe.linkName` (или в веб-интерфейсе портала: «Свойства IFRAME → Начальный URL»). Оси, агрегация и правила агрегации к этому компоненту в статическом режиме не относятся.

Оси (`values`, `filters`, `keys`) присутствуют в конфиге всегда, но в статическом режиме остаются пустыми (`fields: []`). В динамическом режиме они заполняются:

- **Значения** (`values`) — одно строковое поле с URL-ссылками. Агрегация не применяется.
- **Ключи** (`keys`) — поле, управляющее выбором отображаемого адреса. Если в текущей выборке все записи имеют один ключ — показывается ссылка из значений; если ключи разные — показывается начальный URL.
- **Фильтры** (`filters`) — локальные фильтры компонента, сужающие выборку.

URL должен содержать протокол (`https://` или `http://`), иначе фрейм останется пустым.

> Для переключения между несколькими ссылками без датасета применяйте [панель вкладок](tabs-panel.md): кнопки сверху меняют URL фрейма снизу (см. пример ниже).

### Ограничение встраивания (X-Frame-Options)

Некоторые внешние сайты запрещают показ внутри фрейма заголовками `X-Frame-Options: DENY` или `SAMEORIGIN` либо политикой `Content-Security-Policy`. В этом случае содержимое не отобразится — это поведение целевого сайта, а не компонента. Выбирайте ресурсы, разрешающие встраивание, либо специальные embed-адреса (например, `/embed/` у видеохостингов).

## Создание и параметры

> **HsIframe создаётся через MCP** как утилитарный компонент без датасета: `component_crud(action="add", component_type="HsIframe", ...)`. URL фрейма и оформление задаются конфигом и слагами (примеры ниже).

Фрейм относится к компонентам без датасета, поэтому привязка к данным при добавлении не обязательна. Настраиваемые параметры:

| Параметр | Назначение |
|----------|-----------|
| `x`, `y`, `w`, `h` | Позиция и размер компонента в сетке отчёта |
| `title` | Заголовок компонента (по умолчанию скрыт, см. слаг `showtitle`) |
| Слаги оформления | `iframe.linkName`, `iframe.linkTarget`, отступы, рамка, фон |

URL встраивания задаётся слагом `iframe.linkName`; имя окна фрейма — слагом `iframe.linkTarget` (`_self` — обычное поведение, `_blank` — ссылки внутри фрейма открываются в новой вкладке). Прочее оформление — общими слагами (`margin.*`, `outline.*`, `bgColor` и др.); полный перечень — в таблице ниже.

> У фрейма отступы по умолчанию равны 0 — он занимает весь контейнер без зазоров. По умолчанию также включён запрет экспорта (`noexport`): содержимое внешнего ресурса не экспортируется стандартными средствами.

## Пример

Статический фрейм с встроенной веб-страницей (целевая конфигурация, без датасета):

```jsonc
{
  "type": "HsIframe",
  "config": {
    "title": "Встроенная страница",
    "frameUrl": "https://example.com/embed/page",   // ← слаг iframe.linkName
    "link": { "name": "https://example.com/embed/page", "target": "_self" }  // ← iframe.linkName / iframe.linkTarget
  }
}
```

Встраивание видео (embed-адрес) с рамкой и отступами — набор слагов оформления:

```jsonc
{
  "iframe.linkName": "https://www.youtube.com/embed/VIDEO_ID",
  "bgColor": "rgba(0,0,0,1)",
  "margin.l": 8, "margin.r": 8, "margin.t": 8, "margin.b": 8,
  "outline.enabled": true, "outline.width": 2
}
```

Для видеохостингов используйте embed-форму адреса (`/embed/{VIDEO_ID}`), а не обычную ссылку на страницу просмотра — последняя обычно блокируется политикой встраивания.

Паттерн «переключатель + фрейм»: [панель вкладок](tabs-panel.md) сверху меняет URL фрейма снизу. Кнопки переключателя добавляются на панель вкладок отдельным действием (`tabs_button_add` с парами «подпись → ссылка»), а фрейм размещается под ней. Сам фрейм создаётся через веб-интерфейс портала.

## JSON-конфигурация

Сервер собирает и хранит конфигурацию компонента в JSON. Ниже — аннотированная структура фрейма (выверена по билдеру): рядом с ключами указано, что они задают и каким слагом управляются.

```jsonc
{
  "type": "HsIframe",                           // тип компонента
  "config": {
    "title": "Встроенная страница",             // заголовок компонента
    "chartType": "iframe",                      // внутренний тип (фиксирован)
    "showtitle": false,                         // показывать заголовок (по умолчанию скрыт)  ← слаг showtitle
    "maximizable": true,                        // разрешить разворот на весь экран
    "autoApply": true,                          // авто-применение фильтров
    "noexport": true,                           // запретить экспорт (для фрейма по умолчанию true)  ← слаг noexport
    "nocopy": false,                            // запретить копирование                       ← слаг nocopy
    "bgColor": "rgba(255,255,255,1)",           // цвет фона контейнера                        ← слаг bgColor
    "margin":  { "l": 0, "r": 0, "t": 0, "b": 0, "pad": 0 },   // отступы фрейма (по умолчанию 0)  ← слаги margin.l/r/t/b/pad
    "outline": { "enabled": false, "width": 4 },               // рамка                        ← слаги outline.enabled/width/color
    "frameUrl": "",                             // URL встраивания, src тега <iframe> (фронт-ключ)  ← слаг iframe.linkName (синхр. с link.name)
    "link": {                                   // ссылка фрейма
      "name": "",                               //   начальный URL (дублирует frameUrl)        ← слаг iframe.linkName  (json_path link.name)
      "target": "_self"                         //   имя окна фрейма: _self | _blank           ← слаг iframe.linkTarget (json_path link.target)
    },
    "axes": [                                   // оси данных (заполняются только в динамическом режиме)
      { "name": "values",  "type": "values",  "title": "Значения", "visible": true, "fields": [] },  // поле с URL (string)
      { "name": "filters", "type": "filters", "title": "Фильтры",  "fields": [] },                   // локальные фильтры
      { "name": "keys",    "type": "keys",    "title": "Ключи",    "fields": [] }                    // ключ выбора URL
    ]
  }
}
```

> `frameUrl` — это фронт-ключ, а не отдельный MCP-слаг: рендер читает его для атрибута `src`. Через слаг `iframe.linkName` URL пишется сразу в оба ключа (`frameUrl` и `link.name`) — отдельных действий не требуется. Граница HTML-фрейма всегда убрана (`frameborder="0"`); видимая рамка компонента включается слагом `outline.enabled`.

## Все настройки (config_overrides)

Полный перечень слагов этого типа — специфичные для типа и общие оформительские. Колонки: **UI-контрол** — название в панели настроек портала (пусто = прямого UI-контрола нет, настройка только через `config_overrides`); **MCP-слаг** — ключ в `config_overrides`; **JSON-путь** — куда настройка пишется в конфиг и откуда её читает отображение (это и есть «фронт-ключ»; путь в `(скобках)` обрабатывается секционно — итоговый ключ внутри указанной секции конфига); **Тип**; **По умолчанию**.
