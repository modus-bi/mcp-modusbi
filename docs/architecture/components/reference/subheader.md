# Подзаголовок

Тип компонента: `HsSubheaderComponent`

## Описание

Подзаголовок — утилитарный компонент-разделитель: тонкая строка-заголовок секции отчёта со своим
текстом. Применяется как визуальный разделитель между блоками дашборда или как сопроводительная
подпись секции. Собственных данных у него нет — это статический заголовок, а не показатель.

Как и другие утилитарные типы без данных (текстовый блок, изображение, iframe), подзаголовок
добавляется обычным действием `component_crud(action="add", ...)` и размещается в сетке отчёта
координатами `x/y/w/h` — как правило, широкой тонкой строкой вверху (например, `w=48, h=3`).
Привязка к датасету ему не нужна.

## Когда применять

- Разделить дашборд на смысловые секции заголовком («Продажи», «Логистика»).
- Подписать контекст блока отчёта одной короткой строкой.

## Когда не подходит

- Одно-два ключевых числа со сравнением — панель итогов (`HsTotalsPanelV2`).
- Длинный текст или HTML-разметка — текстовый блок (`HsTextBlock`).
- Динамическое значение из данных (дата актуальности, итог и т.п.) — подзаголовок данные не
  отображает; возьмите панель итогов или текстовый блок.

## Создание и оформление

Подзаголовок добавляется как утилитарный компонент без датасета — одним действием `add`:

```python
component_crud(
    action="add",
    report_id=35,
    component_type="HsSubheaderComponent",
    title="Продажи",        # текст заголовка секции
    x=0, y=0, w=48, h=3,    # широкая тонкая строка вверху отчёта
)
```

Компонент получает обычный индекс в сетке (0-based, как у остальных) и по умолчанию исключается из
экспорта и копирования (`noexport=true`, `nocopy=true`). Оформление задаётся через `config_overrides`
слагами из таблицы «Все настройки» ниже — например, текст-метка, фон строки и отступы:

```python
component_crud(
    action="update",
    report_id=35,
    component_idx=4,        # индекс добавленного подзаголовка (0-based) — узнать через components_list
    config_overrides={
        "subtitle": "Раздел: ",          # текст-метка (показывается при showtitle=true)
        "showtitle": True,
        "bgColor": "rgba(240,245,250,1)",
        "margin.l": 8,
        "margin.r": 8,
    },
)
```

Индекс добавленного компонента возвращает `report_operations(action="components_list", report_id=35)`.

## JSON-конфигурация

Подзаголовок хранится как обычный компонент сетки (со своим индексом и позицией в `layouts`).
Базовая структура конфига утилитарного типа — без осей категорий/значений и серий:

```jsonc
{
  "type": "HsSubheaderComponent",
  "config": {
    "chartType": "subheader",            // внутренний тип (фиксирован)
    "title": "Продажи",                  // текст заголовка секции
    "subtitle": "Раздел: ",              // текст-метка (виден при showtitle=true)  // слаг subtitle
    "showtitle": true,                   // показывать метку                        // слаг showtitle
    "noexport": true,                    // исключить из экспорта (по умолч. true)  // слаг noexport
    "nocopy": true,                      // запрет копирования (по умолч. true)     // слаг nocopy
    "margin": { "l": 0, "r": 0 }         // горизонтальные отступы (px)             // слаги margin.l/r
  }
}
```

> Часть общих оформительских слагов для подзаголовка не действует: рамка (`outline.*`) не
> отрисовывается — у этого типа есть только фон строки; из отступов работают горизонтальные
> (`margin.l`, `margin.r`).

## Все настройки (config_overrides)

Полный перечень слагов этого типа — специфичные для типа и общие оформительские. Колонки: **UI-контрол** — название в панели настроек портала (пусто = прямого UI-контрола нет, настройка только через `config_overrides`); **MCP-слаг** — ключ в `config_overrides`; **JSON-путь** — куда настройка пишется в конфиг и откуда её читает отображение (это и есть «фронт-ключ»; путь в `(скобках)` обрабатывается секционно — итоговый ключ внутри указанной секции конфига); **Тип**; **По умолчанию**.
