# Панель изображения

Тип компонента: `HsImagePanel`

## Описание

Панель изображения — утилитарный компонент (без датасета: не загружает данные из источников, служит для оформления и навигации), который отображает на дашборде одно изображение. Это вспомогательный элемент оформления, а не диаграмма: им размещают логотип, иллюстрацию, баннер или иконку. Опционально изображение можно сделать кликабельным — переходом по ссылке.

Компонент работает в двух режимах:

- **Статичный** — картинка загружается напрямую через веб-интерфейс портала и хранится в `config.image`. Датасет не нужен; при добавлении через MCP панель создаётся пустой (с плейсхолдером), а само изображение прикрепляется в UI.
- **Динамический** — картинка берётся из набора данных: поле с изображением в формате base64 (тип `file`) кладётся на ось значений, а поле-фильтр (например, имя файла или ID) — на ось фильтров. Тогда показываемое изображение меняется в зависимости от выбранного значения фильтра.

## Когда применять

- Логотип компании или проекта в шапке/углу дашборда.
- Поясняющие иллюстрации к данным: схемы, планы, чертежи.
- Кликабельный баннер-кнопка с переходом на другой отчёт или внешний URL.
- Декоративные элементы: фон, разделитель, иконка.
- Динамическое фото объекта (товар, сотрудник, место) из БД с переключением по фильтру.

## Когда не подходит

- Для диаграмм и графиков — используйте соответствующий тип чарта.
- Для встраивания внешней веб-страницы — используйте iframe.
- Для форматированного текста — используйте текстовый блок.
- Для галереи из множества картинок — панель показывает одно изображение за раз (для нескольких добавьте несколько панелей).
- Для видео — поддерживаются только статические изображения.

## Датасет не требуется (утилитарный компонент)

В **статичном режиме датасет не нужен**: панель добавляется без привязки к данным, изображение прикрепляется через UI. Оси, агрегация и правила агрегации к этому компоненту не относятся.

В **динамическом режиме** компонент работает с двумя полками данных (осями):

- **Значения** (`values`) — одно поле с base64-изображением, тип `file` (или `image`). Агрегация для него не применяется.
- **Фильтры** (`filters`) — поле, по которому выбирается конкретное изображение (имя файла, ID объекта). Чтобы картинка переключалась по общему фильтру дашборда, привяжите это поле к глобальному фильтру.

Если изображение не задано (ни статичное, ни из данных), панель показывает системный плейсхолдер.

## Параметры добавления

Панель относится к компонентам без датасета, поэтому привязка к данным при добавлении не обязательна. Параметры `dataset_id`, `category_field`, `value_field` для статичного режима не используются; в динамическом режиме поля привязываются отдельно через `component_axes`. Доступные параметры:

| Параметр | Назначение |
|----------|-----------|
| `component_type` | `"HsImagePanel"` — системное имя типа; перечень всех типов отдаёт `component_crud(action="types_list")` |
| `x`, `y`, `w`, `h` | Позиция и размер компонента в сетке отчёта |
| `title` | Заголовок компонента (по умолчанию скрыт, см. слаг `showtitle`) |
| `config_overrides` | Слаги оформления: масштабирование, позиция, повтор, ссылка, рамка, отступы |

Внешний вид настраивается слагами `image.*` (специфичные для типа) и общими оформительскими слагами (`margin.*`, `outline.*`, `bgColor` и т.д.) — полный перечень в таблице ниже.

> У панели изображения слаг `bgColor` пишет значение в ключ `config.backgroundColor` (иной JSON-путь, чем у диаграмм). Сервер обрабатывает это автоматически при применении слага — отдельных действий не требуется.

## Пример

Добавление статичной панели (под логотип) без датасета, вписать изображение по центру с отступами:

```python
component_crud(
    action="add",
    report_id=35,
    component_type="HsImagePanel",
    title="Логотип",
    x=0, y=0, w=8, h=6,
    config_overrides={
        "image.backgroundSize": "contain",
        "image.backgroundPosition": "center center",
        "image.backgroundStyle": "no-repeat",
        "margin.l": 8, "margin.r": 8, "margin.t": 8, "margin.b": 8,
    },
)
```

Здесь настраиваются только параметры отображения. Само изображение (поле `image.src` в конфиге) прикрепляется в веб-интерфейсе (раздел настроек изображения панели); как альтернатива — base64-строку можно передать в `config_overrides["image.src"]`.

Кликабельный баннер с переходом на другой отчёт в новой вкладке. В `image.linkName` можно указать относительный путь (`/report/85`), имя отчёта или полный внешний URL (`https://example.com`):

```python
component_crud(
    action="add",
    report_id=35,
    component_type="HsImagePanel",
    title="Перейти к отчёту по продажам",
    x=0, y=0, w=24, h=4,
    config_overrides={
        "image.backgroundSize": "cover",
        "image.linkName": "/report/85",
        "image.linkTarget": "_blank",
    },
)
```

`image.linkTarget="_self"` открывает ссылку в текущей вкладке, `"_blank"` — в новой.

Здесь `component_crud` — это RPC-метод MCP-сервера (вызов инструмента), а не REST-эндпоинт; `component_idx` в других действиях — 0-based индекс компонента в отчёте.

## Формат данных (динамический режим)

Особого формата не требуется. Нужны две колонки: одна с изображением в base64 (тип `file`) — она идёт в значения; вторая — ключ выбора (имя файла, ID объекта) — она идёт в фильтры. Имена колонок произвольны, важен лишь тип `file`/`image` у поля изображения.

## JSON-конфигурация

Сервер собирает и хранит конфигурацию компонента в JSON. Ниже — аннотированная структура панели изображения (выверена по билдеру): рядом с ключами указано, что они задают и каким слагом управляются. Блок приведён в расширенном формате с комментариями (`//`) для наглядности — валидный JSON комментариев не содержит.

```jsonc
{
  "type": "HsImagePanel",                       // тип компонента (его отдаёт component_crud action="types_list")
  "config": {
    "title": "Логотип",                         // заголовок компонента
    "chartType": "imagePanel",                  // внутренний тип (фиксирован)
    "showtitle": false,                         // показывать заголовок (по умолчанию скрыт)
    "maximizable": true,                        // разрешить разворот на весь экран
    "autoApply": true,                          // авто-применение фильтров
    "noexport": true,                           // запретить экспорт
    "nocopy": true,                             // запретить копирование
    "backgroundColor": "rgba(255,255,255,1)",   // цвет фона панели              ← слаг bgColor пишет сюда (иной JSON-путь, чем у диаграмм)
    "image": null,                              // статичное изображение         ← слаг image.src (null = плейсхолдер/из UI)
    "backgroundSize": "contain",                // масштабирование               ← слаг image.backgroundSize
    "backgroundPosition": "center center",      // позиционирование              ← слаг image.backgroundPosition
    "backgroundStyle": "no-repeat",             // повтор/замощение              ← слаг image.backgroundStyle
    "margin":  { "l": 0, "r": 0, "t": 0, "b": 0, "pad": 0 },   // отступы        ← слаги margin.l/r/t/b/pad
    "outline": { "enabled": false, "width": 4 },               // рамка          ← слаги outline.enabled/width/color
    "link": {                                   // навигация по клику
      "name": "",                               //   URL/путь/имя отчёта         ← слаг image.linkName  (json_path link.name)
      "target": "_self"                         //   _self | _blank              ← слаг image.linkTarget (json_path link.target)
    },
    "axes": [                                   // оси данных (только для динамического режима)
      { "name": "values",  "type": "values",  "title": "Значения", "visible": true, "fields": [] },  // поле type=file (base64)
      { "name": "filters", "type": "filters", "title": "Фильтры",  "fields": [] }                    // поле выбора картинки
    ]
  }
}
```

Значения масштабирования (`image.backgroundSize`): `contain` (вписать, по умолчанию), `cover` (заполнить с обрезкой), `initial` (оригинал), `100% auto` (по ширине), `auto 100%` (по высоте), `100% 100%` (растянуть). Повтор (`image.backgroundStyle`): `no-repeat`, `repeat-x`, `repeat-y`, `repeat`. Девять вариантов позиции — в таблице ниже.

## Все настройки (config_overrides)

Полный перечень слагов этого типа — специфичные для типа и общие оформительские. Колонки: **UI-контрол** — название в панели настроек портала (пусто = прямого UI-контрола нет, настройка только через `config_overrides`); **MCP-слаг** — ключ в `config_overrides`; **JSON-путь** — куда настройка пишется в конфиг и откуда её читает отображение (это и есть «фронт-ключ»; путь в `(скобках)` обрабатывается секционно — итоговый ключ внутри указанной секции конфига); **Тип**; **По умолчанию**. Полный справочник по всем типам — [Справочник настроек](../slugs/by-type.md).
