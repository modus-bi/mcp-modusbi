# Готовность компонентов

Готовность по типам в **процентах** — доля настроек (слагов), реально **рисующихся** в браузере, от
всех применимых к типу. Настройка применяется через `config_overrides`, эффект подтверждается рендером
(скриншот + изменение DOM/SVG).

> Актуально на **2026-06-22**, frontend **3.15.3**. Создаваемых через MCP типов — **28**.

**Рубрика %:** `% = (рисуется + 0.5×(config-only + не подтверждено)) / (рисуется + не рисуется +
config-only + не подтверждено)`. **Вердикт:** ✅ ≥85% · 🟡 50–84% · 🔴 <50% (с учётом функц. блоков).

## Что не проверяется браузером
- **Config-only по природе** — данные, всплывающие подсказки (наведение), интерактив; нет видимого
  статичного результата (проверены на уровне конфигурации).
- **Не подтверждено** — требуют особого датасета/привязки/контраста.
- **Сравнение и рабочий аудиоплеер** — результат не достигается (требует изучения).

## Оформление и CSS отчёта
Report-level CSS (`style_operations`) применяется **поверх стандартного шаблона** портала; набор
поддержанных селекторов задокументирован не полностью, поэтому охват CSS — около **80%**, не 100%.
Для точной работы с дизайном подключайте **Playwright-MCP** и сверяйте оформление визуально
(см. [стилизацию](../components/styling.md) и
[руководство тестировщика](../../start/tester.md)).
