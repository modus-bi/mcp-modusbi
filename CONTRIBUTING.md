# Как внести вклад

Спасибо за интерес к **ModusBI MCP Server**! Это публичная версия проекта.

## Процесс

Разработка ведётся в ветке **`develop`**; `master` — стабильная (релизная) линия.

1. **Форкните** репозиторий и создайте ветку **от `develop`** (например, `feature/...` или `fix/...`).
2. Внесите изменения: для документации держите ссылки рабочими, для кода — следуйте стилю окружающего
   кода.
3. Откройте **Pull Request в `develop`**. Прямой push в `master` и `develop` **закрыт** — все изменения
   проходят через PR и ревью; в `master` они попадают из `develop` при выпуске релиза.
4. В описании PR поясните, что и зачем меняется, и приложите шаги проверки.

## Локальная разработка

- Запуск сервера и подключение к ИИ-клиенту — [docs/start/connect.md](docs/start/connect.md);
  установка из исходников и эксплуатация — [docs/start/for-devops.md](docs/start/for-devops.md).
- Карта документации (по ролям и темам) — [docs/README.md](docs/README.md); устройство сервера —
  [docs/architecture/](docs/architecture/README.md).
- Часть справочников **генерируется** скриптами из `scripts/` (например, каталог слагов). Правьте
  **источник** (`app/tools/config_schema.py`) и регенерируйте, а не сам сгенерированный `.md`/`.json`.

## Что помогает ревью

- Небольшие, сфокусированные PR.
- Для документации — **0 битых ссылок**.
- Для кода — проходящие тесты (`python -m pytest`).

## Безопасность

Об уязвимостях сообщайте **не** через публичный issue, а по [SECURITY.md](SECURITY.md).
