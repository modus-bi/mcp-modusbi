# Генерация SQL для отчётов — сценарии и примеры

> **Коротко:** скажите словами, какой срез данных нужен, — ассистент напишет готовый SQL-запрос
> с правильной сортировкой, аккуратными числами и понятными подписями.
> Запрос можно сразу использовать для создания набора данных.

---

## Когда пригодится

- Нужен **запрос под конкретный график**: топ-N, динамика по месяцам, доли, сравнение периодов.
- Хотите, чтобы числа и порядок строк сразу были **готовы для BI** (без «ступенек» и хаоса на графиках).
- Есть свой запрос, но он **криво рисуется** — нужно поправить под визуализацию.

Если нужен сразу весь дашборд — это `create-dashboard`. Если надо объяснить готовый график — `explain-chart`.

---

## Пример 1. Топ-10 по выручке

**Вы пишете:**
> «Дай запрос: топ-10 товаров по выручке за прошлый год, и чтобы было видно долю каждого.»

**Что сделает ассистент:**
1. Соберёт сумму выручки по товарам и оставит только нужный период.
2. Отсортирует от большего к меньшему и обрежет до 10 строк — рейтинг сразу в правильном порядке.
3. Добавит долю в процентах и округлит числа, чтобы в таблице не было «хвостов» после запятой.
4. Назовёт поля техническими именами и подготовит русские подписи для отчёта.

**Что получите:** готовый запрос — столбчатый график и таблица отрисуются ровно, без ручной правки.

```sql
SELECT
  product AS product,
  SUM(amount) AS revenue,
  ROUND(SUM(amount)::numeric / SUM(SUM(amount)) OVER () * 100, 2) AS share_pct
FROM schema.sales
WHERE date >= '2024-01-01' AND product IS NOT NULL
GROUP BY product
ORDER BY SUM(amount) DESC
LIMIT 10
```

## Пример 2. Динамика по месяцам

**Вы пишете:**
> «Покажи выручку по месяцам — нужно для линейного графика.»

**Что сделает ассистент:**
1. Сгруппирует данные по месяцам.
2. Отсортирует по дате — точки на графике пойдут в хронологическом порядке, а не вперемешку.
3. Округлит средний чек, чтобы цифры выглядели опрятно.

**Что получите:** запрос, готовый для линии динамики — слева направо, месяц за месяцем.

```sql
SELECT
  DATE_TRUNC('month', date) AS month,
  SUM(amount) AS revenue,
  ROUND(AVG(amount::numeric), 2) AS avg_order_value
FROM schema.sales
WHERE date >= '2024-01-01' AND date < '2025-01-01'
GROUP BY DATE_TRUNC('month', date)
ORDER BY DATE_TRUNC('month', date)
```

## Пример 3. Сравнение с прошлым годом

**Вы пишете:**
> «Хочу видеть выручку по месяцам и насколько она выросла к прошлому году.»

**Что сделает ассистент:**
1. Посчитает выручку текущего периода и подтянет значение того же месяца год назад.
2. Посчитает прирост в процентах и защитит расчёт от деления на ноль.
3. Сохранит хронологию, чтобы динамика читалась слева направо.

**Что получите:** запрос для графика «факт vs прошлый год» с готовым процентом роста.

## Полезно знать

- **Говорите обычными словами.** «Заявки по статусам, от большего к меньшему» — этого достаточно.
- **Порядок и числа уже настроены:** строки отсортированы, проценты и суммы округлены, пустые значения отфильтрованы.
- **Поля называются технически** (`revenue`, `order_count`), а на графиках и в таблицах будут русские подписи.
- **Запрос готов к делу:** его можно сразу подать на создание набора данных, а потом строить дашборд.
- **Можно уточнять по шагам:** «добавь фильтр по региону», «округли до целых», «покажи топ-20 вместо 10».
