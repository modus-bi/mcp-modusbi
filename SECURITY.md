# Политика безопасности

## Как сообщить об уязвимости

Пожалуйста, **не открывайте публичный issue** для уязвимостей безопасности — сообщайте приватно:

- через **GitHub Security Advisories**: вкладка **Security → Report a vulnerability** этого репозитория
  (приватный канал, рекомендуется); либо
- письмом на **it@modus.bi** с темой «security: mcp-modusbi».

В сообщении укажите версию, шаги воспроизведения и потенциальное влияние. Мы постараемся ответить в
разумный срок и согласовать раскрытие после выпуска исправления.

## Безопасность при использовании сервера

ModusBI MCP Server выполняет действия на портале от имени учётной записи и под управлением
ИИ-ассистента. Вопросы безопасности доступа — креденшалы портала, права учётной записи,
prompt-injection, выбор режима `readonly` / `readwrite`, «один пользователь = один сеанс» — описаны в
[DISCLAIMER.md](DISCLAIMER.md). Эта зона ответственности лежит на стороне пользователя.
